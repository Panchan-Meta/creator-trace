# スマホのパスキーを使ってPCからログイン

このアプリの初回認証は招待URLからのパスキー登録です。パスワード認証はありません。登録済みのパスキーでログインした後、スマホ用のパスキーを追加できます。

1. 既存のパスキーでログインし、「セキュリティ設定」を開きます。
2. 「パスキーを登録する」を押します。
3. Windowsセキュリティまたはブラウザーの認証画面で「iPhone、iPad、またはAndroidデバイス」や「別のデバイス」を選びます。
4. 表示されたQRコードをスマホのカメラで読み取ります。
5. スマホで指紋・顔認証またはPINを使って承認します。
6. PCのアプリで「パスキーを登録しました」と、登録済み件数の増加を確認します。
7. 「ログアウト」を押し、「パスキーでログイン」を押します。
8. スマホを使う選択肢を選び、QRコードを読み取ってスマホで承認します。
9. PCに自分の修了証が表示されることを確認します。

初回の招待URLからもスマホへの登録を選べます。本人用招待と情報利用への同意を確認してから登録してください。

PCとスマホは近くに置き、両方のBluetoothとスマホのインターネット接続を有効にしてください。本番環境ではHTTPSと、サイトのホスト名に一致するRP_ID・APP_ORIGINが必要です。

QRコードはOS・ブラウザーが生成します。アプリはスマホでの認証を促しますが、選択肢の文言や順序はブラウザー・OSによって異なります。対応するWindowsのEdgeまたはChromeと、iPhone／Androidで上記手順を実機確認してください。認証をキャンセルした場合の再試行も確認してください。

自動テストは署名付きのソフトウェア認証器を使い、登録・追加登録・ログアウト・ログインと認可を検証します。OSのQR画面、Bluetooth、実機の生体認証は自動テストの対象外です。

既存環境への反映前に `0004_session_passkey_registration.sql` をD1へ適用してください。この変更ではデプロイや本番マイグレーションを実行していません。
